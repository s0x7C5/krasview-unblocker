# Krasview Unblocker

Расширение для Chrome и Яндекс.Браузера. Чинит недоступное видео на витринах
krasview: там, где сайт показывает заглушку, поднимает плеер и подставляет ему
рабочий источник.

Рабочее видео не трогается.

Что при этом восстанавливается: **картинка и одна звуковая дорожка**, в лучшем
доступном качестве.

Само по себе лучшее качество не получается. Сайт выключает у плеера адаптивный
выбор и ставит потолок в 720p, а при выключенном выборе плеер решает один раз
при загрузке, отталкиваясь от оценки канала в 1.35 Мбит/с — и если 720p весит
больше, молча остаётся на 360p. Поэтому расширение снимает потолок и выбирает
вариант с наибольшей высотой явно. Ручного переключателя качества нет.

Чего **нет**: меню субтитров и переключателя аудиодорожек. На заглушке
конфига плеера не остаётся, а эндпоинт приложения отдаёт только адрес файла и
никаких метаданных о дорожках. Взять их неоткуда, поэтому в конфиг они не
передаются.

## Установка

Расширения нет в магазинах, поэтому ставится вручную.

**Яндекс.Браузер** — самый простой путь: собрать `.crx` (см. ниже) и
перетащить его на страницу `browser://extensions`.

**Chrome** — перетаскивание сторонних `.crx` заблокировано, поэтому:
`chrome://extensions` → включить «Режим разработчика» → «Загрузить
распакованное расширение» → выбрать папку `extension`.

## Сборка `.crx`

В репозитории только исходники. Пакет собирается браузером:

```
chrome.exe --pack-extension="путь\к\extension" --pack-extension-key="key.pem"
```

Ключ `key.pem` в репозиторий не входит. Если его нет, Chrome создаст новый при
первой упаковке — сохраните его: из ключа вычисляется идентификатор
расширения, и со сменой ключа браузер сочтёт сборку другим расширением, а не
обновлением.

## Как это работает

Приложение krasview получает прямые ссылки не там, где сайт: у API есть
отдельный эндпоинт, отдающий готовый адрес файла, и подписка для него не
нужна. Расширение ходит тем же путём, используя сессию, под которой вы уже
вошли на сайте, — своего логина и пароля у него нет и ничего не хранится.
